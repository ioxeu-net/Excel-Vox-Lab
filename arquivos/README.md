
# Arquivos — Excel Vox Lab

Esta pasta reúne os materiais complementares utilizados pelo Excel Vox Lab.

Os arquivos servem de apoio às aulas, atividades práticas, exemplos e consultas durante o aprendizado.

## Estrutura

```text
arquivos/
├── README.md
├── dicionario-excel.json
├── planilhas/
│   └── Exercicio-01-Controle-de-Vendas.xlsx
└── gabaritos/
    └── Gabarito-01-Controle-de-Vendas.xlsx
```

## 1. Dicionário do Excel

O arquivo `dicionario-excel.json` reúne termos, conceitos e explicações utilizados nas aulas.

Cada entrada deve apresentar, sempre que possível:

- Termo ou função.
- Categoria.
- Explicação em linguagem simples.
- Exemplo de utilização.
- Fórmula correspondente, quando aplicável.

O objetivo é facilitar a consulta de quem está aprendendo.

## 2. Planilhas de exercícios

A pasta `planilhas/` contém arquivos para utilização no Excel ou em programas compatíveis.

As planilhas devem:

- Ter nomes claros.
- Apresentar instruções de utilização.
- Conter dados adequados ao nível do exercício.
- Evitar informações pessoais ou reais de terceiros.
- Ser compatíveis com versões comuns do Excel.

## 3. Gabaritos

A pasta `gabaritos/` contém os arquivos de referência para conferência dos exercícios.

Os gabaritos devem apresentar resultados esperados e, quando necessário, fórmulas utilizadas.

**Importante:** os gabaritos são materiais de apoio e não substituem a explicação do raciocínio.

## 4. Organização e manutenção

Ao adicionar novos materiais:

1. Utilize nomes padronizados.
2. Identifique o módulo e o exercício correspondente.
3. Mantenha exercícios separados de gabaritos.
4. Confira se os arquivos abrem corretamente.
5. Atualize este documento quando a estrutura mudar.

## 5. Observação sobre o conteúdo

A existência de um exercício interativo dentro do aplicativo não significa que exista uma planilha XLSX correspondente.

Os arquivos físicos desta pasta devem ser conferidos individualmente antes de serem anunciados como disponíveis.
