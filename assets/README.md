
# Assets — Excel Vox Lab

Esta pasta reúne os recursos visuais utilizados pelo aplicativo.

Os recursos visuais ajudam a construir a identidade do Excel Vox Lab e tornam a experiência de aprendizagem mais agradável e intuitiva.

## Conteúdo previsto

Podem ser armazenados nesta pasta:

- Logotipo do Excel Vox Lab.
- Ícones de navegação.
- Ilustrações didáticas.
- Imagens de apoio às aulas.
- Elementos gráficos da interface.
- Imagem de capa do projeto.

## Organização recomendada

```text
assets/
├── README.md
├── logo/
├── icons/
├── images/
└── illustrations/
```

As subpastas devem ser criadas somente quando houver arquivos correspondentes.

## Recomendações

- Prefira SVG para logotipos e ícones vetoriais.
- Utilize PNG para imagens que precisem de transparência.
- Utilize WebP para imagens fotográficas otimizadas.
- Evite arquivos excessivamente grandes.
- Utilize nomes descritivos e sem espaços.
- Mantenha os caminhos dos arquivos atualizados no HTML e no CSS.

## Identidade visual

A identidade visual do Excel Vox Lab utiliza uma combinação de:

- Papel envelhecido e tons claros.
- Azul profundo.
- Dourado.
- Roxo.
- Laranja.

A aparência deve transmitir conhecimento, confiança, acolhimento e criatividade.

## Direitos de uso

Somente utilize imagens, fontes, ícones e ilustrações próprios ou com licença compatível com o uso pretendido pelo projeto.

Registre a origem e a licença dos recursos externos sempre que necessário.
